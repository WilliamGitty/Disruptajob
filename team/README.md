# Team

Role definitions for a startup that is currently one person and some AI. Each file describes what
that role owns, what it decides alone, what it must not decide alone, and what it would be working
on this month.

**Why write these before hiring anyone:** they're the job you're doing badly right now because
nobody owns it. Reading them tells you which to hire first — and each one doubles as a brief for
getting the thinking done in the meantime, by an advisor, a contractor, or an AI agent.

| Role | Owns | The question they exist to answer |
|---|---|---|
| [CEO](ceo.md) | Direction, capital, the refusals | Are we building the right thing, and can we keep going? |
| [CTO](cto.md) | The product that exists | Does it work, and can it be changed safely? |
| [CMO](cmo.md) | Demand and the story | Do the right people know, and do they believe it? |
| [COO](coo.md) | The things that must happen | Does the loop actually close, repeatedly? |
| [CFO](cfo.md) | Money, runway, obligations | How long have we got, and what are we legally on the hook for? |

## Honest note on sequencing

At this stage one person holds all five, which is normal and fine. The order these stop being
survivable:

1. **COO first** — the moment there are real users, somebody must watch every one of them and chase
   the loop that doesn't close. This is the first job that breaks.
2. **CMO second** — supply is the hard side of this marketplace, and it doesn't appear by itself.
3. **CTO third** — only once the product needs to be reliable rather than fast-moving.
4. **CFO as a fractional** — needed from the first invoice, not as a full-time hire for years.

The CEO is not on that list because that one isn't delegable.
