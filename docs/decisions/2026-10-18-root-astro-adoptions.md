# Adopted from Root Astro's operating system, 18 Oct 2026

The founder shared Lee Arthur's Operating Map and Publishing Process (Root Astro LLP). Lee
runs the same experiment as us, a principal with an AI crew, eight months further in. We
adopted the principles and skipped the machinery.

**Adopted:**
1. Uptime dead-man switch (.github/workflows/uptime.yml): site failure opens a GitHub issue,
   which emails the founder. The October Fly outage was found by the founder failing to load
   his own site; never again.
2. Monday digest: a scheduled task posts site health, backup status, real-signup count and
   the week's one priority, every Monday 9am.
3. This folder: one file per decision, same day, where the next person finds it.
4. Two prohibitions binding the AI (now in CLAUDE.md): never generate more for the founder
   to read than the decision needs; never invent proposals that add to his queue. Reports
   lead What, So What, Now What.
5. Silence never publishes, for CONTENT: outward-facing words (articles, guides, campaign
   copy) wait for the founder's yes. Code keeps auto-deploying; tests are its gate.
6. Answer guides: future content aims at the justification questions our readers ask AI
   assistants (portfolio instead of CV? experience without the title?), because answer pages
   get cited and citations are the beachhead's first touch.
7. Kill criteria on content, date attached, to be set when guides ship.
8. Parked for the employer side: the refundable founding-deposit as the willingness-to-pay
   test that compliments cannot fake.

**Rejected, with reason:** the five-agent crew, Linear, hourly fires, the 05:30 rhythm.
Machinery for two principals and a content calendar; we are one founder before the first
real user. Principles yes, org chart no.
